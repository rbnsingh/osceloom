# OSCE Loom — instructions for Claude

## Standing instruction: update `practice.html`
Whenever the user sends new material (a case, OSCE station, marking criteria,
model answer, notes, correction or any other content), add it to or update
`practice.html` by default — no need to ask first. Only skip this if the user
says the message is not meant for the practice file.

- Match the existing structure, classes and styling of cases already in
  `practice.html` (e.g. `.ps`, `.model-answer`, `.volunteer-card`,
  `.hx-section`, `.crit`).
- Edit an existing case in place rather than duplicating it.
- Keep content pitched at a 5th-year medical student and aligned with
  Australian guidelines (eTG, RACGP, ANZCOR, NHMRC, etc.) where applicable.
- After editing, commit and push the change.
